# 材料在庫管理システム（React版）

Reactで構築された包括的な材料在庫管理システムです。

## 特徴

- ⚛️ React 18を使用したモダンなSPA
- 📊 Chart.jsによる美しいグラフ表示
- 💾 localStorageによるデータ永続化
- 📤 CSV/Excelエクスポート機能
- 🔔 リアルタイム在庫アラート
- 📱 **PWA対応 - モバイルアプリとしてインストール可能** ⭐ NEW
- 📷 **バーコード/QRコードスキャン機能** ⭐ NEW
- 🔄 オフライン対応（Service Worker）
- 📲 iOS/Android対応

## 主要機能

### 📝 材料マスタ管理
- 材料情報の登録・削除
- 最低在庫数・適正在庫数の設定
- ロケーション管理（倉庫・棚番号）

### 📥 入庫管理
- 入庫データの登録
- ロットNO・仕入先情報の記録
- 自動在庫数更新

### 📤 出庫管理
- 出庫データの登録
- 使用先・工番の記録
- 在庫不足チェック

### 📋 在庫照会
- リアルタイム在庫状況の確認
- ステータスバッジ表示
- 多様なフィルタリング機能

### 📜 履歴管理
- 全入出庫履歴の記録
- 日付・材料・種別による絞り込み

### 📊 ダッシュボード
- 在庫統計情報
- 在庫アラート一覧
- 在庫推移グラフ
- 材料別在庫グラフ

## セットアップ

### 前提条件
- Node.js 18以上

### インストール

```bash
cd react-inventory
npm install
```

### 開発サーバー起動

```bash
npm run dev
```

ブラウザで `http://localhost:5173` を開いてください。

### ビルド

```bash
npm run build
```

ビルドされたファイルは `dist` フォルダに出力されます。

### プレビュー

```bash
npm run preview
```

## 技術スタック

- **フレームワーク**: React 18.2
- **ビルドツール**: Vite 5.0
- **グラフライブラリ**: Chart.js 4.4 + react-chartjs-2
- **Excelライブラリ**: SheetJS (xlsx)
- **バーコード/QRコード**: html5-qrcode, qrcode
- **スタイリング**: Vanilla CSS
- **PWA**: Service Worker, Web App Manifest

## 📱 PWA・モバイル機能

### PWAとしてインストール

#### Android (Chrome)
1. ブラウザでアプリを開く
2. メニュー（⋮）→「ホーム画面に追加」
3. 「追加」をタップ

#### iOS (Safari)
1. Safariでアプリを開く
2. 共有ボタン（□↑）→「ホーム画面に追加」
3. 「追加」をタップ

#### PC (Chrome/Edge)
1. アドレスバーのインストールアイコンをクリック
2. 「インストール」をクリック

### バーコード/QRコードスキャン

#### 使い方
1. 「材料マスタ」または「入出庫」タブを開く
2. 「📷 バーコードスキャン」ボタンをクリック
3. カメラ権限を許可
4. バーコードをカメラに向ける
5. 自動的にスキャンして入力

#### 対応形式
- QRコード
- CODE-128
- CODE-39
- EAN-13
- EAN-8

### オフライン機能
- Service Workerによるキャッシング
- オフラインでもアプリ使用可能
- localStorageでデータ永続化

### アイコン作成
PWAアイコンの作成方法は `CREATE-ICONS.md` を参照してください。

詳細なガイドは `PWA-MOBILE-GUIDE.md` を参照してください。

## データ永続化

データはブラウザのlocalStorageに保存されます。
- ブラウザのキャッシュをクリアするとデータが削除されます
- 重要なデータは定期的にCSV/Excel形式でエクスポートしてください
