# 材料在庫管理システム（React版）

Reactで構築された包括的な材料在庫管理システムです。

## 特徴

- ⚛️ React 18を使用したモダンなSPA
- 📊 Chart.jsによる美しいグラフ表示
- 💾 localStorageによるデータ永続化
- 📤 CSV/Excelエクスポート機能
- 🔔 リアルタイム在庫アラート
- 📱 レスポンシブデザイン

## 主要機能

### 📝 材料マスタ管理
- 材料情報の登録・削除
- 最低在庫数・適正在庫数の設定
- ロケーション管理（倉庫・棚番号）

### 📥 入庫管理
- 入庫データの登録
- ロットNO・仕入先情報の記録
- 自動在庫数更新

### 📤 出庫管理
- 出庫データの登録
- 使用先・工番の記録
- 在庫不足チェック

### 📋 在庫照会
- リアルタイム在庫状況の確認
- ステータスバッジ表示
- 多様なフィルタリング機能

### 📜 履歴管理
- 全入出庫履歴の記録
- 日付・材料・種別による絞り込み

### 📊 ダッシュボード
- 在庫統計情報
- 在庫アラート一覧
- 在庫推移グラフ
- 材料別在庫グラフ

## セットアップ

### 前提条件
- Node.js 18以上

### インストール

```bash
cd react-inventory
npm install
```

### 開発サーバー起動

```bash
npm run dev
```

ブラウザで `http://localhost:5173` を開いてください。

### ビルド

```bash
npm run build
```

ビルドされたファイルは `dist` フォルダに出力されます。

### プレビュー

```bash
npm run preview
```

## 技術スタック

- **フレームワーク**: React 18.2
- **ビルドツール**: Vite 5.0
- **グラフライブラリ**: Chart.js 4.4 + react-chartjs-2
- **Excelライブラリ**: SheetJS (xlsx)
- **スタイリング**: Vanilla CSS

## データ永続化

データはブラウザのlocalStorageに保存されます。
- ブラウザのキャッシュをクリアするとデータが削除されます
- 重要なデータは定期的にCSV/Excel形式でエクスポートしてください
