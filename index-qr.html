📦 QRコード在庫管理

iPhoneで2次元コードを読み取り在庫管理

⚠️ HTTPS接続が必要です

iPhoneのカメラを使用するには、セキュアな接続（HTTPS）が必要です。

ローカルファイル（file://）では動作しません。

✅ 推奨：オンラインで使用

📱 アプリを開く
注意： このボタンが動作しない場合は、以下の方法をお試しください。

📖 使い方（HTTPS環境で）

  1. Webサーバーでこのファイルをホスティング
  2. HTTPS接続でアクセス
  3. 「スキャン開始」をタップ
  4. カメラ許可を承認
  5. QRコード/バーコードをスキャン

🚀 簡単セットアップ方法

方法1: GitHub Pages（無料・推奨）

  1. GitHubリポジトリの Settings を開く
  2. 左メニューの Pages をクリック
  3. Source で Branch を選択（例：main または claude/qr-inventory-app-spsRg）
  4. Save をクリック
  5. 数分後、URLが発行されます

方法2: ローカルHTTPSサーバー

macOS/Linux:

python3 -m http.server 8000

ブラウザで http://localhost:8000/inventory-qr.html を開く

※ただし、カメラ機能はHTTPSが必要なため、ngrokなどのトンネリングサービスを使用してください

方法3: ngrok（HTTPSトンネル）

  1. ngrokをインストール（ngrok.com）
  2. ローカルサーバーを起動: python3 -m http.server 8000
  3. ngrokでトンネル: ngrok http 8000
  4. 表示されたHTTPS URLにアクセス
